# Vinod Rathod — Developer Portfolio

A responsive, dark professional portfolio built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

Search `src/App.tsx` and replace the placeholders:
- `vinod.rathod@example.com` with your preferred public email
- `https://github.com/` with your GitHub profile and each project's repository/demo URL
- `https://linkedin.com/` with your LinkedIn profile
- Add your PDF as `public/Vinod_Rathod_Resume.pdf`
- Confirm the project descriptions, employment dates, education, and certifications are accurate

## Deploy

Import the project into Vercel or Netlify. Use `npm run build` as the build command and `dist` as the output directory.

## Notes

Project cards currently use stylized CSS previews, so no external image assets are required. Keep project claims accurate and link only to repositories or demos that are publicly available.
